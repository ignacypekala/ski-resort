# Ski resort
Ski resort simulation in java

## Gradle
Use the following command to run:

### the project
```
./gradlew run
```

###  the test suite
```
./gradlew test
```

## Structure
- main project logic:
    ```
    app/src/main/java/io/github/ignacypekala/
    ```
- tests:
    ```
    app/src/test/java/io/github/ignacypekala/
    ```

The entry point of the program is `io.github.ignacypekala.simulation.Simulation`.
